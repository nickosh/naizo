# nakajs — Edge Cases: Resolution Ledger

Track boundary cases, subtle failure modes, and their resolution status. Documentation or explicit risk acceptance alone does not resolve an underlying behavioral defect.

Resolution kinds:

- **ADR** — resolved by a design decision recorded in [DECISIONS.md](DECISIONS.md) (`Dxx`).
- **fix** — implementation and regression test landed.
- **doc** — behavior is intentional and explicitly stated in the relevant specification or contract.
- **PARTIAL** — one independently tested slice landed; remaining exposure stays explicit.
- **OPEN** — planned or unresolved; never mark closed from a plan or documentation note alone.

| EC01 | External AI agent edits `#nakadb` on disk while browser `localStorage` holds older cached state                                                                        | **ADR D04 / fix (`src/index.ts`, `naka.js`, `tests/naka.test.ts`)**: `initNaka()` compares current `#nakadb` text against `nakadb_disk_hash_<pathname>` in `localStorage`. When they differ, external disk state wins over `localStorage` cache and hydrates the DOM (see `EC06` for refresh mutation bug). |
| EC02 | `IndexedDB` restricted on `file://` protocol or `window.showSaveFilePicker` unavailable in non-Chromium browsers                                                       | **PARTIAL (`src/index.ts`, `naka.js`)**: `idbStore` / `loadHandleFromIDB` guard `indexedDB` access and resolve `null`; `connectOrResumeDisk()` falls back to downloading an HTML Blob snapshot when `showSaveFilePicker` is absent. Automated test and `URL.revokeObjectURL` cleanup scheduled in `M4.1`. |
| EC03 | Auto-injected list buttons (`.naka-item-tools`, `.naka-list-footer`), styles (`#__nakadb_styles__`), and status pill (`#__nakadb_host__`) would duplicate on disk save | **ADR D05 / fix (`src/index.ts`, `naka.js`, `tests/naka.test.ts`)**: runtime elements are stripped from the cloned document in `getCleanHtmlString()` prior to disk write or `Naka.exportHTML()` (see `EC07` / `D12` for separating `data-naka-runtime` from user `naka-ignore`).                          |
| EC04 | Malformed or empty JSON inside `<script id="nakadb" type="application/json">`                                                                                          | **fix (`src/index.ts`, `naka.js`, `tests/naka.test.ts`)**: `parseDbScript()` catches `JSON.parse` errors, logs a console warning, and falls back to `{ _meta: {}, fields: {}, lists: {}, custom: {} }`.                                                                                                   |
| EC05 | Corrupted JSON in `localStorage` (`PAGE_KEY`) during `init()`, or non-`contenteditable` `[naka]` / `[data-naka]` text elements inside auto-inferred list `<template>`  | **fix (`src/index.ts`, `naka.js`, `tests/naka.test.ts`)**: `parseCachedState()` wraps `localStorage` `JSON.parse` in a `try/catch` fallback, and `clearElementValue()` clears `textContent` on plain non-input elements when inferring a list `<template>`.                                               |
| EC06 | `initNaka()` saves post-capture `#nakadb` text (with mutated `_meta.updatedAt` and reformatted indentation) to `snapshotKey`, wiping `localStorage` edits on refresh   | **OPEN (`D13`, `M4.1`)**: record unmutated disk `#nakadb` payload in `snapshotKey` before `captureDomToState()` runs and avoid bumping `_meta.updatedAt` during read-only hydration.                                                                                                                      |
| EC07 | `naka-ignore` on user elements (e.g., `#rps-slider` in `index.html`) excludes them from state tracking but deletes them from saved/exported HTML                       | **OPEN (`D12`, `M4.2`)**: keep `naka-ignore` / `data-naka-ignore` exclusively for skipping state binding, and use `data-naka-runtime` on injected runtime UI stripped by `getCleanHtmlString()`.                                                                                                          |
| EC08 | Literal `</script>` or `<!--` inside `#nakadb` JSON strings prematurely closes `<script id="nakadb">` in serialized HTML and corrupts the document on reload           | **OPEN (`D13`, `M4.1`)**: escape `</script` (`<\/script`) and `<!--` (`<\!--`) when serializing JSON into `<script id="nakadb">`.                                                                                                                                                                         |
| EC09 | Auto-inferred `<template naka-template>` is baked into saved HTML and overrides later edits to `[naka-item]` markup, yet stripping it unconditionally breaks empty lists | **OPEN (`D14`, `M4.3`)**: mark inferred templates with `data-naka-auto-template`, regenerate from the first `[naka-item]` on boot when no explicit template exists, and strip on export when the list has $\ge 1$ item (preserving when $0$ items).                                                       |
| EC10 | Open browser tab with active `FileSystemFileHandle` overwrites external AI agent disk edits if the user interacts with the page before refreshing                      | **OPEN (`D13`, `M4.1`)**: inspect `await fileHandle.getFile()` on window `focus` / `visibilitychange` and before `writeToDisk()` to auto-hydrate external `#nakadb` changes and guard against stale writes.                                                                                               |
| EC11 | Implicit global `TRACKED_SELECTOR` hijacks unannotated page inputs, shifts `field_${idx}` keys when list items change, and collides across `localhost` projects        | **OPEN (`D12`, `D13`, `M4.1`–`M4.2`)**: require explicit `naka` / `data-naka` on standalone fields, prioritize `name` over `id` for radio inputs inside lists, and normalize storage keys (`/index.html` → `/`, optional `naka-id` / `_meta.id`).                                                         |
| EC12 | Element binding & typing defects: `number`/`range` string coercion, `<details>` child wipe, `contenteditable` variants, and `<textarea>` cursor jump on `input`        | **OPEN (`D14`, `M4.2`)**: coerce `number`/`range` to `number \| null`, bind `HTMLDetailsElement.open`, support `<select multiple>` and `contenteditable="plaintext-only"`, guard non-leaf elements, and defer attribute baking to hydration/export.                                                        |
| EC13 | List repeater DOM issues: invalid `<tr>`/`<tbody>` control placement, ignored self-bound `[naka-item]`, cross-row radio `name` collision, and unrevoked Blob URLs      | **OPEN (`D14`, `M4.1`, `M4.3`)**: place table list controls in valid table DOM positions, bind `[naka]` on the `[naka-item]` root element itself, scope radio `name` attributes per item row, and call `URL.revokeObjectURL()` after Blob download.                                                        |
