# nakajs — Edge Cases: Resolution Ledger

Track boundary cases, subtle failure modes, and their resolution status. Documentation or explicit risk acceptance alone does not resolve an underlying behavioral defect.

Resolution kinds:

- **ADR** — resolved by a design decision recorded in [DECISIONS.md](DECISIONS.md) (`Dxx`).
- **fix** — implementation and regression test landed.
- **doc** — behavior is intentional and explicitly stated in the relevant specification or contract.
- **PARTIAL** — one independently tested slice landed; remaining exposure stays explicit.
- **OPEN** — planned or unresolved; never mark closed from a plan or documentation note alone.

| EC01 | External AI agent edits `#nakadb` on disk while browser `localStorage` holds older cached state                                                                                                                                                                                                                 | **ADR D04 / fix (`src/index.ts`, `naka.js`, `tests/naka.test.ts`)**: `initNaka()` compares current `#nakadb` text against `nakadb_disk_hash_<pathname>` in `localStorage`. When they differ, external disk state wins over `localStorage` cache and hydrates the DOM (see `EC06` for refresh mutation bug).                                           |

| EC07 | `naka-ignore` on user elements (e.g., `#rps-slider` in `index.html`) excludes them from state tracking but deletes them from saved/exported HTML                                                                                                                                                                | **OPEN (`D12`, `D16`, `M4.3`)**: keep `naka-ignore` / `data-naka-ignore` exclusively for skipping state binding, and use `data-naka-runtime` on injected runtime UI stripped only by `Naka.exportHTML()` and the Blob fallback; surgical disk sync never touches body markup.                                                                         |
| EC08 | Literal `</script>` or `<!--` inside `#nakadb` JSON strings prematurely closes `<script id="nakadb">` in serialized HTML and corrupts the document on reload                                                                                                                                                    | **OPEN (`D13`, `M4.1`)**: escape `</script` (`<\/script`) and `<!--` (`<\!--`) when serializing JSON into `<script id="nakadb">`.                                                                                                                                                                                                                     |
| EC09 | Auto-inferred `<template naka-template>` is baked into saved HTML and overrides later edits to `[naka-item]` markup, yet stripping it unconditionally breaks empty lists                                                                                                                                        | **OPEN (`D14`, `D16`, `M4.3`)**: mark inferred templates with `data-naka-auto-template` and regenerate from the first `[naka-item]` on boot. | EC11 | Implicit global `TRACKED_SELECTOR` hijacks unannotated page inputs, shifts `field_${idx}` keys when list items change, and collides across `localhost` projects                                                                                                                                                 | **OPEN (`D15`, `D13`, `M4.1`–`M4.2`)**: bind exclusively via `naka` / `data-naka` / `data-naka-field` with no `id`, `name`, or `field_${idx}` fallback anywhere, and normalize storage keys (`/index.html` → `/`, optional `naka-id` / `_meta.id`).
